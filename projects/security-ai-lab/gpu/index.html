CPU vs GPU 성능 비교 — 보안 탐지 모델

개인 프로젝트완료

앞 단계 탐지 모델 구조(XGBoost, MLP)를 같은 데이터·같은 하이퍼파라미터로 CPU와 GPU(Colab T4)에서 학습·추론했습니다. 목적은 "GPU가 빠르다"를 확인하는 게 아니라, 어떤 운영 조건에서 GPU가 필요한지를 숫자로 판단하는 것입니다.

GPU 연산은 비동기라서 측정 전후에 torch.cuda.synchronize()를 넣었고, 워밍업 후 반복 측정한 중앙값을 썼습니다. GPU 추론 입력은 미리 GPU 메모리에 올려(cupy·텐서) CPU↔GPU 복사 비용을 뺐습니다.

CPU 처리량은 Colab vCPU 2개 측정값을 32코어 서버로 환산한 추정치입니다(코어당 처리량 × 32 × 확장 효율 70%). GPU는 T4 1장 실측치입니다. 측정 범위는 모델 연산만이며 로그 파싱·특징 추출 시간은 포함하지 않습니다. batch 1,024에서는 XGBoost의 경우 32코어 CPU 서버(환산)가 T4 1장보다 처리량이 높습니다.
